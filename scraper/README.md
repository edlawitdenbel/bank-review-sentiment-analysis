# Google Play Review Scraper

## Overview

This scraper collects customer reviews from the Google Play Store for Ethiopian banking applications.

The collected reviews are used for sentiment analysis, theme extraction, and machine learning tasks in this project.

## Target Applications

- Commercial Bank of Ethiopia (CBE)
- Bank of Abyssinia (BOA)
- Dashen Bank

## Technologies

- JavaScript
- Node.js

## Output

The scraper generates review data in JSON format, which is later cleaned and processed using Python.

## How to Run

Install dependencies:

```bash
npm install
```

Run the scraper:

```bash
node scraper.js
```

The generated JSON file can then be used in the preprocessing notebooks.
